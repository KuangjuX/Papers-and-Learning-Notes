# Kernel design 绘图

让读者从图中追踪同一个 tile：它从哪里来，落在哪个存储区域，由谁执行哪条计算路径，状态由谁持有，何时释放。若用户认可某个子图，只修改待改部分。

## 先建立实现依据

- 固定硬件、kernel 路径和源码版本。核对输入/输出 shape、分块轴、CTA 映射、warp/warpgroup 角色、存储位置、指令与同步条件。未确认的调度或耗时不补画成事实。
- 区分三个视角：算法数据流、硬件 ownership、执行依赖。依据当前问题选择主视角；算法矩阵式旁写一个“SM”标签，并不能代替硬件映射。
- 算法图画真实张量轴与索引关系。硬件图至少能回答：哪段 query/head/token/feature 属于哪个 CTA 或 warpgroup，哪种硬件单元执行什么运算，累加器和归一化状态在哪里。
- 对多个消费者核对共享与交换：概率 tile、统计量、输出维度是否跨角色传递；QK ownership 与 PV/output ownership 可能沿不同轴划分，不能默认每个角色独立完成同一个 attention tile。

- FSA / NSA：query 薄片、稀疏网格、非连续 gather；层叠方向对应真实张量轴。
- SageAttention：小矩阵与片上计算边界，适合计算公式展开。
- FlashAttention-4 Fig. 1：张量分块与 CTA/SM/执行单元对齐，通过相同 tile ID 建立对应。
- FlashAttention-3 Fig. 1/2：分别按执行角色、算子组织泳道；明确同一 iteration 跨阶段流动与交叠。
- PageWeaver Fig. 3：存储槽与执行角色并列，ready/release 事件表达缓冲生命周期。

## 把算法映射到硬件

1. 以同名 tile、索引和颜色连接算法与实现。明确矩阵两轴，特别是 query 与 head、逻辑 token tile 与物理 buffer 的区别。
2. 用有边界的 HBM、SMEM、寄存器区域表示驻留位置。按 CTA/warpgroup/warp 组织执行泳道；在算子内部标明 Tensor Core / CUDA Core、MMA/copy 等已核实的执行方式，不把 warpgroup 误画成专属 Tensor Core。
3. 将计算与状态 ownership 直接画出来：QK 对应哪个 KV tile，PV 对应哪个输出列段，哪些统计量或概率 tile 需要交换。必要时用局部矩阵分区，避免用长句替代分区。
4. 缓冲展示 load → ready → consume → release → refill；标出释放粒度和最后消费者。不同特征段可分别复用时，不用整块释放箭头掩盖这一差别。
5. 区分依赖图、定性调度和实测时间线。依赖图不以列对齐暗示同时发生；定性时序注明非等比例；实测时间线才使用耗时轴。异步指令的发射、完成与缓冲释放是不同事件，不能将箭头交叠等同于完全隐藏加载延迟。
6. 用户要求 pipeline 调度时，必须给出明确的时间方向，展开足以看清复用的相邻迭代，将加载/驻留、计算角色与 ready/free 事件放到同一时间基准上；仅有角色框、矩阵式或单轮数据依赖图不能替代时间顺序。未实测时使用满足源码依赖的定性调度，异步区间明确是发射到 wait 还是实际执行，不能暗示同一硬件单元的实测并行占用。
7. 确有跨迭代交叠时，保留 tile/iteration 标识和相关 wait/barrier；证据不足时以角色和事件依赖表达，避免照抄参考论文的 ping-pong 时间线。

## 视觉表达与交付

- 画张量、切片、token 条带、稀疏关系与分区。空间层次由有语义的薄片、堆叠轴和局部展开形成；不统一添加厚侧面、顶面和阴影。算子与存储区域用清楚的边界，避免大量文字框复述正文。
- 使用鲜明、可区分的少量颜色。先确定颜色表示数据对象、iteration 还是操作类型，再跨子图保持一致；数据箭头与同步/复用箭头用不同线型并给图例。
- 总览和硬件展开分别布局；复杂子图可以单独导出以保持正文宽度的可读性。只保留与当前机制有关的标注，不顺带增加用户未关注的量化、架构分支或推测性能。
- 复杂图优先用 draw.io 或 PowerPoint 的原生对象，保留 `.drawio`/`.pptx` 并实际用该工具导出 SVG/PNG；不能以一张嵌入位图冒充可编辑图。后续以用户编辑过的原生文件为准，重跑生成脚本前核对是否会覆盖修改。
- 查看最终渲染图和正文宽度预览：检查轴、tile ID、角色归属、箭头端点、交叉线、文字尺寸和裁切。成功导出不替代视觉与语义检查。图注明确自绘和实现来源。
- 写入笔记时沿用目标仓库的 Issue/PR 与文档检查流程；仅绘制独立文件不额外触发发布。交付图片、可编辑源文件和实际完成的校验。
