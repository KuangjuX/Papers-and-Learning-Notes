# 神经网络

<a id="简单的概念"></a>

## 全连接层

手写数字识别把图像像素作为输入，输出数字 0–9 的十个类别分数。若需要类别概率，可以对这十个 logits 做 softmax。

一层全连接网络写为：

$$
z=Wa+b,\qquad h=\phi(z).
$$

若输入 $a\in\mathbb R^n$、输出有 $m$ 个单元，则 $W\in\mathbb R^{m\times n}$、$b\in\mathbb R^m$。第 $i$ 个单元先计算 $z_i=\sum_j W_{ij}a_j+b_i$，再经过激活函数 $\phi$。例如 $a=[1,2]^T$、$W=[3,-1]$、$b=1$，得到 $z=2$；ReLU 输出为 2，sigmoid 输出约为 0.881。

激活函数引入非线性，不要求所有神经元都落在 0–1：sigmoid 的输出在这个区间内，ReLU 则是 $\max(0,z)$，没有固定上界。偏置平移激活前的数值，不是另一个输入样本。

<a id="如何进行训练"></a>

## 损失与参数更新

损失衡量预测与目标的差异，具体形式由任务决定。回归可以使用平方误差，分类常用交叉熵；不能把所有损失都定义成“输出减目标的平方和”。对固定训练数据，损失是模型参数的函数。

梯度给出参数变化对损失的一阶影响。梯度下降按 $\theta' = \theta-\eta\nabla_\theta L$ 更新参数；负梯度是欧氏范数约束下的局部最速下降方向，但有限步长不保证每次下降，也不保证找到全局最小值。

例如 $L(w)=\tfrac12(w-3)^2$，在 $w=1$ 处梯度为 $-2$。取学习率 $\eta=0.1$，更新到 $w'=1.2$，损失从 2 降到 1.62。神经网络用反向传播沿计算图的链式法则求出梯度，优化器再用梯度更新参数，二者承担不同职责。

<a id="反向传播算法"></a>

## 反向传播与隐藏表示

每个参数收到所有依赖它的计算路径贡献的梯度；多个样本的贡献按损失定义求和或取平均。Minibatch SGD 用一小批样本估计梯度，减少单次更新需要处理的数据量，不需要每次遍历完整训练集。具体矩阵推导见 [神经网络反向传播](../07_Books_and_Technical_References/Courses/DL-System/01-neural-network-backward.md)。

**个人疑问：隐藏层的单元是否具有可解释的含义？** 输入像素和输出类别有明确语义，隐藏表示则由训练共同形成。把数字“8”理解为两个圈、把“9”理解为圈和竖线，可以作为特征组合的直觉，但不能据此认定某个单元一定编码其中一笔；这需要对实际模型的激活与输入响应进行检验。
